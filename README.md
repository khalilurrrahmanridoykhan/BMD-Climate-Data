# BMD-Climate-Data

Daily weather data collected from the Bangladesh Meteorological Department (BMD), covering all 8 divisions and 46 stations nationwide.

- daily/BMD_Daily_Weather_<date>.xlsx - one snapshot per day
- BMD_Daily_Weather_All_Divisions.xlsx - cumulative log of every day collected so far

Collected automatically once daily at 23:00 Asia/Dhaka.
